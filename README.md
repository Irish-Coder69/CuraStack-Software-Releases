# CuraStack Software Releases

This repository is the official public distribution channel for CuraStack Software installers and update metadata.

- It contains compiled release artifacts only. The application source code is maintained in a private repository.
- Production installers are Authenticode-signed by the CuraStack publisher.
- CuraStack verifies the published SHA-256 digest before launching an update.
- Do not install files presented as CuraStack releases from any other repository or publisher.

No patient or customer data is stored in this repository.
